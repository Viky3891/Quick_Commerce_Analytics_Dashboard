# Quick Commerce Analytics Dashboard

An executive-level interactive Excel dashboard analyzing 1M+ rows of multi-platform quick commerce transactions across 8 major brands (Swiggy Instamart, Blinkit, Zepto, BigBasket, Flipkart Minutes, Amazon Now, Dunzo, JioMart).

* **Total Quantity:** 9.7M

### Key Features & Interactivity
* **Dynamic Slicers:** Instant filtering enabled for **City** (e.g., Hyderabad), **Category** (e.g., Snacks), and **Payment Mode** (e.g., Credit Card).
* **Visual Breakdown:** Category-wise sales trends, payment mode shares donut chart, and delivery time city heatmaps.
* **Advanced Backend:** Built using Pivot Tables, GETPIVOTDATA, and optimized data modeling.
