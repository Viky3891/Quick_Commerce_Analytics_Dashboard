### 🛠️ Key Features & Interactivity
* **Dynamic Slicers:** Instant filtering enabled for **City** (e.g., Hyderabad), **Category** (e.g., Snacks), and **Payment Mode** (e.g., Credit Card)[cite: 7].
* **Visual Breakdown:** Category-wise sales trends, payment mode shares donut chart, and delivery time city heatmaps[cite: 7].
* **Advanced Backend:** Built using Pivot Tables, GETPIVOTDATA, and optimized data modeling.
